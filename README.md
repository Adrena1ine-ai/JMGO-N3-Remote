# JMGO N3 — канал публикации модифицированной панели

**Неофициальный проект**, не продукт JMGO. Это публичный канал распространения только подписанных APK и release notes. Исходники адаптации, OEM/декодированные библиотеки, прошивки, секреты подписи и серверные данные здесь не публикуются.

## Фактически опубликовано

- Latest stable release: [n3-v95.4-code3674](https://github.com/Adrena1ine-ai/JMGO-N3-Remote/releases/tag/n3-v95.4-code3674).
- APK: JMGO_N3_REMOTE_V95_4_CODE3674_SIGNED.apk.
- SHA-256: fc3545a9950ba6e14d182918e099a6df541ca52bafe2fde99120b1e9446bc20c.
- Машинные метаданные: n3-update.json, прикреплён к тому же релизу.
- Android package: com.jmgo.setting.clone. Следующие обновления должны использовать тот же Android signing certificate и больший versionCode.
- Проверено: сборка APK, подпись, ZIP, GitHub release/metadata. **Реальная установка и функция проверки обновлений на проекторе N3 пока не подтверждены.**

## Важное предупреждение по V95.4

В первоначальной реализации GitHub-обновлятора использовался Android AlertDialog из контекста OEM settings overlay. На родственном JMGO N5S эта реализация вызвала воспроизводимое аварийное завершение панели (WindowManager.BadTokenException). Поэтому **возможность проверки обновлений в опубликованной N3 V95.4 считать экспериментальной/непринятой**, пока не выпущена и не проверена исправленная N3 сборка. Не утверждать обратного на основании того, что APK подписана и опубликована.

В следующих локальных версиях для N5S ошибка исправлена выводом статуса в существующую строку native ConfigItem и привязкой к реальному OEM SystemPage; эти сборки **не являются публичными обновлениями N3** и не заменяют необходимость N3 hardware acceptance.

## Как должен работать исправленный updater

После подтверждённой на конкретной модели установки приложения пользователь вручную нажимает «Проверить обновления панели». Приложение получает публичный GitHub Releases latest, при ошибке API использует публичный n3-update.json, сравнивает Android versionCode, загружает предложенную APK, проверяет SHA256, package name и сертификат и передаёт её стандартному Android PackageInstaller. Установка требует явного согласия пользователя; скрытая/автоматическая установка не предусмотрена.

**Важно:** одно совпадение Android package/signature не доказывает совместимость N3 и N5S. Перед выпуском общей ленты обновлений необходимо определить модельную совместимость и/или разделить model-specific каналы. Не использовать N3 релиз для обновления N5S без такой проверки.

## Ограничения и воспроизводимость

Размещать в GitHub Releases только: подписанную APK для подтверждённых моделей, проверенный SHA256, имя/номер версии, target models, n3-update.json и протокол физической приёмки. Не размещать сырой APK другой модели как универсальный. Для реального инкрементального обновления Android versionCode новой версии должен быть больше установленного.
