# JMGO N3 — обновления пользовательской панели

Публичный репозиторий **релизов** для модифицированной панели управления JMGO N3. Репозиторий не содержит исходную прошивку JMGO, сторонние исходники, ключи подписи или личные данные.

Новые подписанные APK публикуются в [Releases](https://github.com/Adrena1ine-ai/JMGO-N3-Remote/releases). Внутри панели: **Настройки → О системе → Проверить обновления панели**. Приложение сравнивает versionCode, проверяет SHA-256 и подлинность подписи, после подтверждения пользователя запускает системную установку поверх предыдущей версии.

> Неофициальный инструмент. Не является официальным продуктом JMGO. Устанавливайте только на совместимые устройства и не удаляйте установленную копию перед обновлением.
